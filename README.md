# Boeing 787 MCP Trainer

787 MCP / FMC(CDU) / PFD / ND / EFIS 연동 연습용 단일 HTML 트레이너 (개인 학습용).

- 파일: `index.html` (브라우저/iPad에서 바로 열기, 외부 의존성 없음)
- 레슨: 지상 · 이륙/초기 상승 · MCP 용어 · 상승 · 강하(RKSI 33R) · 접근(ILS) · 복행
- 버전: v1.1
- 화면: **비행** 배치(EFIS·MCP·PFD·ND·CDU·기어/플랩/EICAS를 한 화면에 자동 맞춤) + 떠 있는 설명 패널, **분할**, **세로**
- 듀얼 모니터: 헤더의 "설명 창 분리 ⧉" → 설명·단계·MCP 해설이 별도 창으로 열리고 두 창이 실시간 동기화됩니다 (설명 창에서 레슨 선택·TO/GA·일시정지 가능). 같은 주소 + `#script`로 직접 열어도 됩니다.

> 학습 보조용 단순화 모델입니다. 속도·수치·절차는 교육용 가정이며, 실제 운항은 회사 787 FCOM/FCTM을 기준으로 하세요.
